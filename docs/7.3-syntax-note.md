# 7.3-syntax note (this package's own compat gate)

`metrictower/mainnet-client` must run on **PHP >= 7.3** (WordPress hosts on 7.x run it). Because the
reporter was pulled out of `funnypot-core`, piece C's 7.3 matrix no longer covers this code — **this
package owns its 7.3 lane** (`.github/workflows/ci.yml`, the `7.3` job). The dev host is PHP 8.x, so a
local `php -l` is blind to 7.4+ syntax; the 7.3 CI job (and a local `php:7.3-cli` lint) is authoritative.

## Do NOT use (7.4+/8.0+ only)

- **Constructor property promotion** (`__construct(private int $x)`) — 8.0. Assign to declared props.
- **Enums** — 8.1. Verdict/source/action are `const` strings on their value objects.
- **`match`** — 8.0. Use `switch` / `if`.
- **Nullsafe `?->`** — 8.0.
- **`??=`** — 7.4.
- **Typed properties** (`private int $x`, `private ?PDO $db`) — 7.4. Value objects use **untyped props +
  docblocks**; `PdoSqliteReportQueue` uses an untyped `$db` with an `@var` docblock.
- **Union types** in signatures (`int|string`) — 8.0. Use a nullable single type or `@param` docblocks.
- **Arrow functions** (`fn() => …`) — 7.4. Use full `function () { … }` closures (the seams are passed as
  `callable`s).
- **Named arguments** — 8.0. `Config` is built via `fromArray()` (an assoc-array builder) exactly so a
  consumer is never pinned to positional order.
- **Trailing comma in parameter *declarations*** — 8.0 (trailing commas in *calls* are 7.3-fine).
- **8.0 stdlib** (`str_contains`, `str_starts_with`, `array_key_first`, …).

## What IS 7.3-legal and used

Scalar/array/nullable **parameter and return** types (`?int`, `?array`, `bool`, `void`, class names),
`??` null-coalescing, `intdiv`, `random_bytes`, spread in calls. Object-shaped seams (`Cache`,
`Transport`, `ReportQueue`) are plain interfaces.

## Verifying locally without a 7.3 host

```
# Parse-lint every file under a real 7.3 interpreter:
docker run --rm -v "$PWD":/app -w /app php:7.3-cli \
  sh -c 'for f in $(find src tests -name "*.php"); do php -l "$f" >/dev/null || exit 1; done; echo OK'

# Run the whole suite on 7.3 (curl+pdo_sqlite+sodium are built into php:7.3-cli, so the
# conditional SQLite/transport tests RUN, not skip):
docker run --rm -v "$PWD":/app -w /app php:7.3-cli php vendor/bin/phpunit
```
